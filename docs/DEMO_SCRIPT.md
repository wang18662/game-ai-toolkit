# 60 秒 Demo 录制脚本（草稿 · 待药审阅）

> 用途：完成标准第②条「能录 1 分钟 demo」的提词脚本。
> 这是 AI 先备好的草稿，你回来只需决定「录不录 / 怎么改」，不用从零想词。

## 录制前准备（一条命令）

```
D:\anaconda\python.exe examples\run_skirmish.py
```

- 默认：红队 = 行为树 BT，蓝队 = 效用 Utility，**你指挥蓝队**。
- 打开窗口后**先点击游戏窗口**（键盘焦点），再按键。
- 按键：`1` 进攻 `2` 防守 `3` 集火 `4` 撤退 `5` 自动 `T` 换队。
- 战斗结束会自动重开（loop 默认开），适合反复录。

## 60 秒时间轴

| 时间 | 动作 | 口播（照念即可） |
|------|------|------------------|
| 0:00–0:06 | 开场，画面定格两军 | 「这是一个引擎无关的游戏 AI 工具库。红队跑行为树，蓝队跑效用 AI，现在由我指挥蓝队。」 |
| 0:06–0:28 | 按 `5`（自动）让红队来追你 | 「注意红队追我的时候，撞到障碍物不是硬停，而是侧向绕过去。这是个体层的避障 steering——之前它直线撞墙卡死 46 次，改成绕行后归零。避障归'身体'，怎么打归'大脑'，两层分开。」 |
| 0:28–0:45 | 按 `4` 全队后撤，再按 `1` 全队前压 | 「我按 4 全队撤退，按 1 全队进攻。指令不是评分表里的一个软权重，而是硬约束——进攻时 AI 绝不会擅自撤退，这样'指挥'才有意义。」 |
| 0:45–0:55 | 画面停留，口播（可不切窗口） | 「这套确定性核心还能接生成式 LLM：LLM 只产出'台词 + 意图'，由一个确定性的校验器守门，越权的意图会被拦下、断网自动降级模板台词。AI 不接管决策，只做叙事。」 |
| 0:55–1:00 | 收尾 | 「一个引擎无关、可 pip 安装、还带 LLM 集成层的游戏 AI 工具库。」 |

## 备选：三段各说一句（如果怕念长句）

1. **避障**：「红队追我时会绕障碍，不会卡死——个体避障和群体决策分两层。」
2. **指令门控**：「我按撤退就撤、按进攻就冲——指令是硬约束，不是软建议。」
3. **混合架构**：「LLM 只产出台词和意图，确定性校验器守门，越权拦截、断网降级。」

## 三处设计对应的口播依据（面试时展开用，demo 里一句话带过即可）

- 个体避障（身体）vs 群体决策（大脑）：`steering.obstacle_avoidance` + `Agent.tick` 替代式仲裁。
- 指令 = 硬约束选项门控：`UtilityBrain._allowed_options`，禁 Retreat / 只 Retreat / 全自主。
- 确定性 core + 生成式 LLM + 确定性 validator：`LlmBrain.respond`，`validator` 不是第二个 LLM。
